# Reliability benchmark scaffold

This package is the design-only scaffold associated with
[RFC #764](https://github.com/OpenHands/benchmarks/issues/764).

It contains verified architecture notes, a proposed deterministic
fault-schedule and scoring design, public type contracts, and intentionally
unimplemented entrypoints. It does not contain fault injection or benchmark
execution logic.

Implementation is deferred until maintainers confirm the repository, initial
fault boundary, and milestone scope.
